# PDF Tools — Privacy

## Our promise

**Your files never leave your device.** Every tool on PDF Tools runs 100% in your browser. There is no server receiving your PDFs — because there is no server at all.

## What this means technically

- When you select or drop files, they are read into your browser's memory and processed locally by code running on your device (Web Workers).
- Nothing is uploaded, nothing is stored online, nothing is sent to analytics. We cannot see your files even if we wanted to.
- Closing the tab discards everything. There is no account, no history, no trace.

## What we do collect

- Nothing about your files. If privacy-friendly analytics is enabled in the future (page views only, no file data), it will be stated here first.

## The one exception

Password-protected PDFs: when you unlock or protect a file, the password you type is used only inside your browser to process that file. It is never transmitted anywhere.
